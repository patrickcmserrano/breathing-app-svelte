# Changelog - WebOasis 4-7-8

## 03/05/2025 - Melhorias no Sistema de Notificações

### Adicionado
- Service worker para gerenciar notificações em segundo plano
- Notificações funcionam mesmo quando o app não está aberto ou em foco
- Indicador visual de status das notificações
- Botão para teste de notificação
- Botão para verificação manual de notificações
- Ferramenta de diagnóstico de service worker e notificações
- Vibração nas notificações para dispositivos móveis

### Modificado
- Melhor tratamento de erros no sistema de notificações
- Inicialização automática do verificador de notificações quando o app carrega
- Notificações mais persistentes (30 segundos)
- Interface de usuário da tela de configurações de notificações melhorada
- Método de verificação de horários para maior precisão

### Corrigido
- Problema onde as notificações não apareciam nos horários programados
- Notificações não funcionavam quando o navegador estava em segundo plano
- Falta de feedback ao usuário sobre o status das notificações
- Inicialização inconsistente do sistema de notificações

## 25/04/2025 - Implementação da Funcionalidade de Mantra

### Adicionado
- Tela de configuração de mantra personalizado
- Armazenamento persistente do mantra do usuário
- Exibição do mantra durante os exercícios de respiração
- Inclusão do mantra nas notificações

### Modificado
- Interface de usuário da tela de configurações para incluir seção de mantra
- Formato das notificações para mostrar o mantra personalizado

## 15/04/2025 - Versão Inicial 1.0.0

### Adicionado
- Técnica de respiração 4-7-8 com animação visual
- Configurações de notificação básicas
- Suporte para múltiplos idiomas (9 idiomas)
- Seleção de temas claro/escuro
- Estatísticas de sessão
- Biblioteca de sons relaxantes
- Modo offline completo
